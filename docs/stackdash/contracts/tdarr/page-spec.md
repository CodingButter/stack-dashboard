# Tdarr — Page Specification (contract v1.0.0)

> Generated by the StackDash migration apparatus (apparatus `164e0f0`) from
> `tdarr-redesign.png@05b7163a` and static analysis of the existing Tdarr slice.
> Provenance: `static-analysis`. Machine-readable source of truth:
> `page-spec.json` + the seven sibling contract artifacts.

## Regions

1. **KPI strip** (`tdarr.kpi`) — 6 summary cards: Library files, Transcodes,
   Health checks, Space saved, Queue depth, Active workers.
2. **I/O Governor panel** (`tdarr.governor`) — governor state, active streams,
   stream bandwidth, SAB cap, lane holder/timeout, governor-paused nodes,
   freshness readout.
3. **Node cards** (`tdarr.nodes`) — one card per node: name, status badges,
   worker limits, queue, and per-worker rows (current file, stage, progress).
4. **Bottom analytics row** (`tdarr.analytics`) — queue-depth trend, worker
   throughput trend, uptime / service health.

## Stable-ID scheme

`<page>.<region>.<section>.<component>[.<field>]`, all segments `[a-z0-9-]+`.
Root page id: `tdarr`.

## Load-bearing producer facts (verified against code)

- **KPI + node fields** arrive via `http-poll` (medium 10–15s) — the Tdarr
  poller client hits `/api/v2/get-nodes` and `/api/v2/cruddb`
  (`src/poller/clients/tdarr.ts`) and persists a `box=tdarr` nodes snapshot.
- **Governor** is `server-derived` from an `agent/governor` snapshot in
  `buildGovernor` (`src/lib/panels/assemble.ts`). Two first-class states:
  `governor === null` (never received → unavailable) and `governor.running ===
  false` (gate dead/stale, also forced false when the snapshot row is older than
  `AGENT_STALE_MS`).
- **Worker stage** is `local-derived` via `workerStage(status)`
  (`src/lib/panels/tdarr-stage.ts`).
- **Write-back progress** (the trap) is `server-derived` from
  `governor.nodes[].replaceProgress.{pct,mbps}`, consumed only when
  `workerStage().isFinalizing`. It is **not** the worker `percentage`, which is
  `0` during a Replace/Copy network write. See `gap-analysis.md`.
